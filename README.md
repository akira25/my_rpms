# SDR and Ham Radio related RPMs

This repository holds the specfiles for some Ham Radio related RPMs, that I packaged
primarily for personal usage. They are built automatically in the
[mhuebner/sdr](https://copr.fedorainfracloud.org/coprs/mhuebner/sdr/) COPR for
Fedora (current releases and rawhide, x86_64 and aarch64):

    sudo dnf copr enable mhuebner/sdr

If you find them useful, you might install them from there. Please mind, that this
project is a private initiative only. I do not (actively) maintain the software
packaged by these files.

Special care needs to be taken with the `-next` packages. These follow the main
branch of the sources directly. Please consider, that this might lead to using
bleeding-edge software, containing bugs.
